# Kleurlicht

Gebruik je scherm als gratis videobel-verlichting.

👉 https://lucasreinds.github.io/kleurlicht

Kleurlicht is een kleine browsertool waarmee je een scherm verandert in een kleurvlak dat als verlichting kan dienen tijdens video calls.
In plaats van extra lampen neer te zetten, gebruik je gewoon een tweede scherm (of je laptop) als lichtbron.

## Zo gebruik je het
1. Open de tool in je browser
2. Kies een kleur
3. Stel de helderheid in
4. Zet het scherm naast je webcam

Je kunt favoriete kleuren opslaan en het bedieningspaneel verbergen zodat alleen het kleurlicht zichtbaar blijft.

## Handige toetsen
H of Esc  
toon of verberg het bedieningspaneel

## Waarom dit bestaat
Tijdens videobellen is een beetje licht vaak al genoeg om er beter uit te zien.  
Omdat schermen toch al licht geven, kun je ze net zo goed als kleurlicht gebruiken.

## Techniek
Deze tool is een eenvoudige HTML-webapp en werkt volledig in de browser.  
Er zijn geen installaties of externe libraries nodig.
